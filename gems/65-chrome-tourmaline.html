Chrome Tourmaline — 1.60 ct Trillion

A deep green trillion colored by chromium — the same element that colors emerald.

A trillion-cut chrome tourmaline in a deep, saturated green at 1.60 carats. Chrome tourmaline takes its color from chromium and vanadium, the same trace elements responsible for emerald's green, and it is generally natural in color rather than treated. It is sometimes marketed as a cleaner, more affordable alternative to emerald, which is a fair way to think about it.

Every stone in this collection is described exactly as its original box label reads.
